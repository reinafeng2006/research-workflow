# 智能体角色与项目专长

状态：v0.9.4 新增。**这是一套未经验证的默认设计**：「按项目专长分工，比通用角色产出更多有价值的方向」这一点还没有在真实项目中测过，见第 6 节。人和 AI 谁落槌，以[人机分工](division-of-labor.md)为准。

## 1. 两层

区分智能体的是**专长**——看什么、能读什么、交出什么——而不是性格。专长改变想法的内容，性格主要改变说法。

### 固定职能：所有项目都一样

| 职能 | 做什么 | 为什么固定 |
| --- | --- | --- |
| 协调者 | 契约、分工、依赖、预算、阶段转换；四格播报 | 保持整体一致 |
| 产出者 | 生成选项、实现、执行、分析、起草，并自查 | 负责实质产出 |
| 独立核验者 | 查底层证据，逐项记 pass / fail / not_verifiable | 门槛 G2 要求它没参与过被核验的产物 |
| 质疑者 | 查假设、反例、竞争解释；**找没被任何专长覆盖的角度** | 专门唱反调，不能依赖项目恰好配了这个视角 |

这一层不随项目变，因为它存在的理由是结构性的，与领域无关。独立性规则见[共享控制](shared-controls.md)第 6 节。

### 项目专长：按项目、按阶段配置

取代原来笼统的"方法专家（按需）"。每个项目、每个阶段可以不同：Step 1 可能需要领域视角，Step 2 需要方法和统计视角，Step 5 需要目标读者视角。

## 2. 两条轴：学科视角 × 研究职能

一个具体的专长 = **学科视角 × 研究职能**，按需组合。例如"心理测量"（心理学 × 测量）、"计量识别"（经济学 × 研究设计）、"版本校勘"（文学 × 史料与文本）。

- **学科视角**提供该学科特有的知识、惯例和公认难点。同样叫"测量"，心理学讲的是心理测量的效度，物理学讲的是仪器校准，经济学讲的是识别。
- **研究职能**提供跨学科都要做的那类工作，并保证不漏项。

### 学科视角

- **本学科**：查已有工作、领域惯例与公认难点。
- **近邻与远邻学科**：专门用于发散。最有价值的扩展问题常常来自借用邻近学科的框架；发散时可以给它们分配算子，问"这个学科会怎么看这个问题"（见[发散与评估](divergence-and-appraisal.md)第 1 节）。

**学科不由本文自编一套**，而是采用 OECD《弗拉斯卡蒂手册》2015 年版第 3 章的研究与发展领域分类（FORD）。该分类按研究内容划分，共 6 个大类、42 个子领域。逐类过一遍，判断本学科在哪一类、近邻和远邻在哪里。

> 核验状态（2026-11-04）：
> - **已核对**：出处为 OECD (2015)《弗拉斯卡蒂手册 2015》第 3 章（ISBN 978-92-6423880-0）；第 1 级"大类"6 项、第 2 级"子领域"42 项；主要按研究内容划分；大类之一为"工程与技术"。来源：[联合国统计司分类登记页](https://unstats.un.org/unsd/classifications/Family/Detail/1039)，属官方登记对手册的转述，不是手册原文。
> - **未核对**：其余五个大类和 42 个子领域的名称。登记页不列名单，UNESCO 的相关页面已失效，OECD 网站拒绝自动访问。常见写法是自然科学、工程与技术、医学与健康科学、农业科学、社会科学、人文与艺术，但在核对手册原文之前不当作已确认。

### 研究职能

按研究类型分组，避免默认所有研究都是量化实证。这是查漏用的工作清单，**不声称完整**；推导出的专长不在清单里也完全可以。

| 适用 | 职能 | 主要看什么 | 常用阶段 |
| --- | --- | --- | --- |
| 所有研究 | 文献与新颖性 | 问题是否已被回答、最近的邻近工作 | 1 |
| 所有研究 | 研究设计 | 论证或研究的整体构造：对照、偏差、可比性，或论证结构 | 1、2 |
| 所有研究 | 伦理与许可 | 研究对象、知情同意、合规、材料使用权、潜在危害 | 1、2、6 |
| 所有研究 | 目标读者与用途 | 谁会用这个答案、怎么用、会误读成什么 | 1、5 |
| 所有研究 | 交付与接收方 | 格式、渠道、期限、验收要求 | 5、6 |
| 量化实证 | 测量 | 结果怎么量、效度与信度 | 1、2 |
| 量化实证 | 统计与推断 | 样本、效应量、多重比较、不确定性 | 2、4 |
| 量化实证 | 数据与获取 | 来源、许可、可获得性、质量、预留数据 | 1、2、3 |
| 质性 | 访谈、观察与编码 | 抽样逻辑、编码方案、饱和、可信度 | 2、4 |
| 质性 | 立场与反身性 | 研究者的位置如何影响材料与解读 | 2、5 |
| 理论与形式 | 定义、证明与反例 | 概念是否定义清楚、证明是否完整、边界情形 | 2、4 |
| 理论与形式 | 模型构造 | 假设是否必要、结论对假设的依赖 | 1、2 |
| 史料与文本 | 史料批判与版本 | 来源可靠性、版本差异、档案的完整性 | 1、2、4 |
| 史料与文本 | 诠释 | 解读是否有文本支持、竞争解读 | 4、5 |
| 构建与工程 | 实现与可复现性 | 代码、环境、算力与成本、他人能否复现 | 3、4 |
| 构建与工程 | 基准与评测 | 比较对象是否公平、评测是否测到想测的东西 | 2、4 |

## 3. 专长怎么产生

1. **推导**。AI 从两处推出专长，并写明每个专长来自哪一处：
   - 研究问题的组成：对象、结果测量、对比、边界、要支持的决定。例如"结果测量"需要测量视角，"要支持的决定"需要使用者视角。
   - [评估矩阵](../templates/appraisal-matrix.md)的敏感性：推荐最依赖哪几个分数或假设，就派专长去盯那几处。专长花在项目最不确定的地方，而不是平均分配。
2. **两条轴分别查漏**。学科轴：按 FORD 大类逐类判断本学科、近邻、远邻；职能轴：先找出本项目属于哪几种研究类型，再把"所有研究"和对应类型的职能逐条过一遍。每条写"需要"、"不需要"或"不需要，因为……"。
3. **你批准名单**。名单并入 Step 1 的「档位与可行性检查契约」授权点一起批；之后各阶段的调整在该阶段的启动授权里批。不新增授权点。
4. **数量**：每阶段 2–4 个专长；其中学科视角最多 1 个本学科加 1–2 个近邻或远邻。这是提案，按项目调整。

## 4. 每个专长写清四件事

| 项 | 例：心理测量（心理学 × 测量） |
| --- | --- |
| 看什么 | 量表的效度与信度、测量是否对所有被试等价 |
| 能读什么 | 协议、量表说明、分析计划；不读未获准查看的中间结果 |
| 交出什么 | 对每个候选方向或设计的测量风险清单，指回评估矩阵的底座条目 |
| 不能做什么 | 不替你定阈值；不验收自己参与设计的测量方案 |

通用约束：

- 专长参与了产出，就不能独立验收同一产物——独立性规则对专长同样适用。
- 专长不改变证据规则，也不改变谁落槌。**AI 以某学科视角说的话不是证据**："从经济学看……"之类的判断，仍须按 [Step 1](step-1.md) 的证据规则给出直接来源。一个模型能把某学科视角模拟到什么程度，未经验证。
- 方向记录里，AI 提出的方向写明是**哪个专长**提的，以便事后比较。

## 5. 人格是可选的表现层

名字、头像、口吻可以加在专长之上，用于界面体验。规则：

- 人格不改变专长的四件事。
- 界面上必须说明这些 mate 是不是同一个模型。同一个模型扮演多个角色，不算多个独立视角，"几位 mate 都同意"不是证据。
- 人格能否提高想法的多样性、或提高用户参与讨论的意愿，都**未经验证**。

## 6. 未经验证的部分

- 按专长分工是否比通用角色产出更多你愿意保留的方向。
- 按敏感性派专长是否会让 AI 只盯着已知风险、漏掉未知的。质疑者"找未覆盖角度"的职责是针对这一风险设的对策，它本身也未经验证。
- 每阶段 2–4 个是否合适。
- 一个模型能把某学科视角模拟到什么程度；近邻与远邻学科视角是否真的带来可用的新方向。

方向记录会记下每个方向由哪个专长提出、最后是否入选。攒够几个项目就能比较；在那之前，本文按默认设计执行，不把它当成已证实的结论。
